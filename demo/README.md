# D3-Contour 交互式 Demo

这是一个基于增强版 d3-contour 库的交互式等值线可视化演示。

## 🚀 快速开始

### 启动 Demo

```bash
npm run demo
```

服务器将在 `http://localhost:8080` 启动，在浏览器中打开该地址即可查看 demo。

## 🎨 功能特性

### 1. 数据生成模式

- **高斯分布** - 经典的单峰高斯分布
- **多峰分布** - 多个高斯峰的叠加
- **波浪纹** - 动态的正弦波模式
- **马鞍面** - 数学上的马鞍面形状
- **随机噪声** - 纯随机数据

### 2. 可调整参数

#### 数据控制
- **网格分辨率** (30-150) - 控制生成网格的精细程度
- **噪声强度** (0-50%) - 添加随机噪声的程度

#### 等值线设置
- **等值线数量** (3-20) - 控制生成的等值线层数
- **平滑程度** (0-5) - 路径平滑的迭代次数
- **平滑算法** - Chaikin 算法或 Catmull-Rom 样条

#### 显示选项
- **显示等值面** - 切换填充区域的显示
- **显示等值线** - 切换等值线边界的显示
- **显示标签** - 切换数值标签的显示
- **颜色方案** - Viridis、Plasma、Blues、Heatmap
- **等值面透明度** (0-100%) - 控制填充区域的透明度
- **等值线宽度** (0.5-3.0px) - 控制线条粗细

### 3. 操作按钮

- **生成** - 使用当前设置重新生成可视化
- **随机** - 随机化所有参数设置
- **导出 PNG** - 将当前可视化导出为 PNG 图片

### 4. 实时统计

显示以下信息：
- 生成时间（毫秒）
- 等值面数量
- 等值线数量
- 标签数量

## 🎯 技术实现

### 架构设计

本 demo 完全基于重构后的 d3-contour 库，遵循 Plotly.js 的架构原则：

```
Grid Data
  ↓
generateContoursAuto() - 生成等值线和等值面
  ↓
chaikinSmooth() / catmullRomSmooth() - 路径平滑
  ↓
generateLabelsForContours() - 生成标签
  ↓
removeCollidingLabels() - 碰撞检测
  ↓
renderContoursCanvas() - Canvas 渲染
```

### 核心特性

1. **Isoline-Isoband 一致性**
   - 等值线从等值面边界派生
   - 确保完美的几何对齐

2. **路径级平滑**
   - 不修改原始数据
   - 仅对渲染路径进行几何平滑

3. **智能标签系统**
   - 自动定位最佳位置
   - 跟随路径方向旋转
   - 碰撞检测和消除

4. **高性能渲染**
   - 使用 HTML5 Canvas
   - 支持实时交互
   - 可导出高清图片

## 📸 使用示例

### 示例 1：观察高斯分布的等值线

1. 选择数据模式：**高斯分布**
2. 设置等值线数量：**8**
3. 开启所有显示选项
4. 调整平滑程度观察曲线变化

### 示例 2：比较不同平滑算法

1. 选择数据模式：**多峰分布**
2. 等值线数量：**10**
3. 先使用 **Chaikin 算法**，平滑程度 3
4. 切换到 **Catmull-Rom 样条**，对比效果

### 示例 3：自定义配色方案

1. 选择数据模式：**波浪纹**
2. 尝试不同的颜色方案：
   - **Viridis** - 科学可视化的标准配色
   - **Plasma** - 暖色调渐变
   - **Blues** - 单色渐变
   - **Heatmap** - 热力图配色

### 示例 4：导出高质量图片

1. 调整所有参数到理想状态
2. 调高网格分辨率（如 120）
3. 点击 **导出 PNG** 保存图片

## 🔧 技术细节

### 性能优化

- 使用 `Float32Array` 存储网格数据
- 仅在必要时重新计算等值线
- Canvas 渲染比 SVG 更快

### 浏览器兼容性

支持所有现代浏览器：
- Chrome/Edge 90+
- Firefox 88+
- Safari 14+

### 依赖项

- 原生 ES 模块
- HTML5 Canvas
- 无需额外库

## 🐛 故障排除

### Demo 无法加载

确保：
1. 已运行 `npm run build` 构建库
2. 使用 `npm run demo` 启动服务器
3. 浏览器支持 ES 模块

### 性能问题

如果 demo 运行缓慢：
1. 降低网格分辨率
2. 减少等值线数量
3. 关闭标签显示

### 样式问题

确保浏览器加载了完整的 CSS，清除缓存后重试。
